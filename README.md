# ⚡ NEXUS CALCULATOR

### A Modern Calculator Built with HTML, CSS & JavaScript

A sleek, responsive calculator featuring a modern UI, calculation history and light/dark themes.

## 🌐 Live Demo

[Open Nexus Calculator](https://aryan09-alt.github.io/Nexus-Calculator-/)

## ✨ Features

- Basic Arithmetic Operations
- Percentage Calculation
- Calculation History
- Light & Dark Mode
- Keyboard Support
- Responsive Design
- Modern Glassmorphism UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
